### Summary of Form Functionality

The forms that we will generate and host for RSVP handling will serve as a means of linking the invitees to their status. 

The structure of the form and what the necessary fields are should determine what data gets stored for each invitee. This means that once the fields are set for a given form they cannot be updated, or if they are updated Null values will have to populate for any invitees that have already responded.

Also; might want to add a *Guests Enabled* feature that allows for a limited number of additional guests that the Event Creator can define. *Note: This would have to be uneditable after the fact*

**Please note: Some of the fields will be to verify the invitee when they access the form**
