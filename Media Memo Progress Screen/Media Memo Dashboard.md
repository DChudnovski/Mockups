# Media Memo Dashboard

## Need for a Dashboard

In processing large amounts of media for items there's a need for monitoring tools that can both allow for at a glance insights as well as data dives that can allow for better strategizing and visibility.
 
### 5 Tools/Views for the Dashboard

1. Active Media Memos View
   - Tool/View for seeing the current total amount of items in house that are on Media Memo and seeing the Active Memos and their at a glance Progress

2. Daily 360 Item (Can filter by Tech)
   - Tool/View for seeing the number of items and which items have had 360 done on them in a given day. Lets us see what items are being done by what techs and how many items are done.

3. Time In-House (Historical and Current)
   - Tool/View for seeing the amount of time a Media Memo is in for as well as monitoring sent dates. Using historical data we can determine average actual times vs. Projected times. [Could potentially be expanded to see how long each process takes upon receipt]

4. Item Types; Stone Types etc. and Value In-House
    - Tool/View for monitoring trends of items that are being taken in and what is currently in the house as well as the value of what has been taken-in at a given time.

5. Current Capacity / Pending (Items Needing Media)
    - Tool/View for keeping track of the amount of items that we have in-house and determining what the capacity of the Media Team is.
